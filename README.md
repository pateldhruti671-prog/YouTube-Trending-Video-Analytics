# YouTube Trending Video Analytics

## Project Overview

This project analyzes YouTube trending video data to identify patterns in video views, categories, engagement, sentiment, publishing time, and trending activity.

The project uses Python for data cleaning, analysis, and visualization, and Power BI for interactive dashboard creation.

## Objectives

- Analyze YouTube trending videos
- Identify categories with high average views
- Analyze video engagement
- Perform sentiment analysis on video titles
- Analyze publishing time and day
- Study trending activity over time
- Create an interactive Power BI dashboard

## Tools & Technologies

- Python
- Pandas
- Matplotlib
- Seaborn
- NLTK
- Power BI
- CSV Dataset
